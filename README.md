# HIVE

Self-improving agent harnesses (Cornell CS 4701). An optimizer agent reads evaluation scores and raw traces, then proposes harness edits (prompts, extensions, multi-agent topology) to a Pi-based agent. A trusted controller keeps an edit only if it beats the baseline by more than the measured noise.
